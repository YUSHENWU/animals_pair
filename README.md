# 🐾 動物翻翻牌（A–Z Animals Pair）

一款專為手機與桌面瀏覽器最佳化的雙語記憶翻牌網頁遊戲！收錄 **26 個英文字母（A–Z）對應 26 種動物、共 52 張牌**，支援 **1–4 人同樂與電腦 AI 對戰**，並提供**深淺色主題切換**與**置頂回合提示列**。

## ✨ 遊戲特色

- **A–Z 26 種動物（共 52 張牌）**：每張牌皆有放大的動物視覺、英文字母徽章與中英文名稱，手機小螢幕也能一眼看清。
- **手機優先響應式設計**：
  - 手機直向採用 **4 欄大卡片**排版，動物圖案放大呈現，支援流暢單手滑動與觸控防誤觸。
  - 平板與桌機自動擴展為 5 / 7 / 8 / 13 欄，大螢幕可一覽完整 52 張牌。
- **置頂回合提示列（Sticky Top Bar）**：滑動牌面時，頂部始終固定顯示目前輪到誰、剩餘對數與所有玩家的即時分數。
- **支援 1–4 人與電腦對戰**：
  - **單人挑戰**、**人機對戰**、**2–4 人本地同樂**。
  - 每個玩家欄位皆可自由切換「🧑 玩家」或「🤖 電腦」，並提供 **簡單 / 普通 / 聰明** 三段電腦記憶力難度。
- **深淺色主題切換**：支援淺色溫暖紙感與深色護眼模式，並自動記憶使用者偏好。
- **零外部相依**：純單一 `index.html` 檔案（內建 Web Audio API 合成音效），開箱即玩，也可直接部署於 GitHub Pages。

## 🚀 使用方式

1. 直接用瀏覽器開啟 `index.html` 即可開始遊玩。
2. 點擊右上角 `⚙️` 可切換對戰人數（1–4 人）、人類/電腦組合與 AI 難度。
3. 點擊右上角 `🌙` / `☀️` 可切換深淺色模式，`🔊` / `🔇` 可開關音效。
